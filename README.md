# Pinterest - Center Open Pin

A Chrome userscript for Tampermonkey that moves an open Pinterest Pin toward the center of the screen, keeping related Pins visible around it. The script also attempts to autoplay, loop and unmute open video Pins. Chrome's autoplay settings can affect playback. Restart Chrome to check.

## Install

1. Install Tampermonkey in Chrome and enable **Allow User Scripts** in its extension details. See the [Tampermonkey FAQ](https://www.tampermonkey.net/faq.php#Q209).
2. [Install the userscript](https://lapis-slate-xvar.here.now/pinterest-center-pin.user.js), and select **Install** in Tampermonkey.
3. Refresh Pinterest and open a Pin.

Use the X near the upper-right corner of an open Pin to dismiss it. The script also attempts to autoplay, loop and unmute open video Pins. Chrome's autoplay settings can affect playback.

The **Toggle centered Pins** command in Tampermonkey enables or disables the layout. On smaller screens Pinterest's normal layout is used.

Pinterest may change its layout, which can affect how the script works. Some empty space can remain in the recommendations after closing a Pin.
